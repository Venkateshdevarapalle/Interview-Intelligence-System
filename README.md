# 🎤 Interview Intelligence System

An AI-powered mock interview evaluation platform that analyzes confidence, communication, and professionalism from interview videos.

---

## 🚀 Features
- Upload interview video or conduct live interview
- Automatic topic assignment
- Video analysis (camera presence)
- Audio analysis (speech clarity, confidence)
- NLP-based content analysis
- Final interview score + improvement tips
- Downloadable PDF report

---

## 🛠 Tech Stack
- Streamlit
- OpenCV
- Vosk (Speech-to-text)
- DeepFace (Facial analysis)
- TensorFlow
- MoviePy
- Python

---

## ▶ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
